# 🏢 HH.ru Vacancy Parser & Analyzer

Веб-приложение для парсинга вакансий с [hh.ru](https://hh.ru), анализа требований работодателей и визуализации востребованных навыков.

## 🎯 Что делает проект

| Функция | Описание |
|---------|----------|
| **Поиск вакансий** | По ключевым словам, названию компании или везде |
| **Анализ зарплат** | Средняя верхняя и нижняя граница (с конвертацией валют) |
| **Анализ навыков** | Топ-5 самых востребованных навыков |
| **Сохранение в БД** | Данные сохраняются в SQLite через SQLAlchemy |
| **Веб-интерфейс** | Удобная форма с результатами на Bootstrap |

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| Python 3 | Язык программирования |
| Flask | Веб-фреймворк |
| SQLAlchemy | ORM для работы с БД |
| SQLite | База данных |
| requests | HTTP-запросы к HH API |
| pycbrf | Конвертация валют (курс ЦБ РФ) |
| Bootstrap 5 | Фронтенд |
| Jinja2 | Шаблонизатор |

## 📊 Модели базы данных

### Таблица `words` (ключевые слова)
| Поле | Тип | Описание |
|------|-----|----------|
| id | integer | Первичный ключ |
| word | varchar(50) | Ключевое слово (вакансия) |
| count | real | Количество найденных вакансий |
| up | real | Средняя верхняя граница зарплаты |
| down | real | Средняя нижняя граница зарплаты |

### Таблица `skills` (навыки)
| Поле | Тип | Описание |
|------|-----|----------|
| id | integer | Первичный ключ |
| name | varchar(255) | Название навыка |

### Таблица `wordskills` (связь вакансий и навыков)
| Поле | Тип | Описание |
|------|-----|----------|
| id | integer | Первичный ключ |
| id_word | integer | Foreign Key → words.id |
| id_skill | integer | Foreign Key → skills.id |
| count | real | Количество упоминаний |
| percent | real | Процент упоминаний |

### Таблица `area` (регионы)
| Поле | Тип | Описание |
|------|-----|----------|
| id | integer | Первичный ключ |
| name | varchar(50) | Название региона |
| ind | integer | ID региона в HH API |

## ▶️ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/ваш_аккаунт/hh_flask.git
cd hh_flask
```
### 2. Создание виртуального окружения
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```
### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```
### 4. Создание базы данных
```bash
python database.py
```
### 5. Загрузка регионов
```bash
python area.py
```
### 6. Запуск приложения
```bash
python main_sqlalchemy.py
```
### 7. Открыть в браузере
```text
http://127.0.0.1:5000
```
